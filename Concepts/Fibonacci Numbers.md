# Fibonacci Numbers

Define
$$F_1=F_2=1,\qquad F_n=F_{n-1}+F_{n-2}\quad(n\ge3).$$

See [[Numbers and Sets - Introductory Sheet 2026]], page 1, question 5. That question asks for addition identities, divisibility, the prime-index condition and last-digit periodicity. For worked and incomplete attempts, see [[Numbers and Sets 0 - Handwritten Attempts]], pages 6–7.
