# Cyclic Groups and Element Orders

> [!abstract] In one paragraph
> A cyclic group is generated by one element. There are only two kinds: finite ($\cong C_n\cong\mathbb Z_n$) and infinite ($\cong\mathbb Z$). The order of an element $g$ is the size of the cyclic subgroup it generates — the least $n>0$ with $g^n=e$, if one exists.

## Definitions

- $G$ is **cyclic** if $G=\{g^k:k\in\mathbb Z\}$ for a **generator** $g$. → [[Groups - Chapter 1 Examples and Definitions#Definition — Cyclic group|lecture]]
- **Order** $o(g)=|\langle g\rangle|$ ($\infty$ if $\langle g\rangle\cong\mathbb Z$). → [[Groups - Chapter 1 Examples and Definitions#Definition 1.39 — Order of an element|lecture]]

## Key results

- **Theorem 1.38.** Every cyclic group is $\cong C_n$ for some $n$, or $\cong\mathbb Z$. *Idea:* let $S=\{k>0:g^k=e\}$. If $S=\varnothing$, $k\mapsto g^k$ is an isomorphism $\mathbb Z\to G$; otherwise with $n=\min S$ it is an isomorphism $\mathbb Z_n\to G$ (divide exponents by $n$). → [[Groups - Chapter 1 Examples and Definitions#Theorem 1.38 — Classification of cyclic groups|proof]]

## Examples

- $C_n$ (generator $e^{2\pi i/n}$), $\mathbb Z_n$ (generator $1$), the trivial group, $\mathbb Z$ (generator $1$).
- In $D_{2n}$: $o(r)=n$, $o(s)=2$.

## Pitfalls

- Different exponents can give the same element: in $C_n$, $g^k=g^{k+n}$.
