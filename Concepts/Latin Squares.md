# Latin Squares

A Latin square is an array of symbols such that each row and column contains the same set of symbols, and no row or column contains a duplicated entry. A correctly completed Sudoku puzzle forms a Latin square.

Source: [[Groups - Introductory Sheet 2026]], page 2, question 8. The sheet asks about Cayley tables of finite groups and an associative closed operation on a non-empty finite set whose table is a Latin square. These are exercise prompts; no proof is supplied in the sheet, and [[Groups 1 - Handwritten Attempts]], page 9, contains only the question 8 heading.
